Philosophy

人人可运维，事事可自动，处处可信任

不追求重平台，只做三件事：让接入足够简单、让操作足够自动、让数据足够安全。

01 / ZERO-INVASION

零侵入接入

单文件 Agent，一条命令安装，无需 Docker、无需额外运行时，秒级上线；卸载即恢复，不留任何痕迹。

02 / TRIPLE-SYNC

三端实时同步

Web 控制台、桌面客户端与 Agent 通过 WSS 实时互通，随时随地进入你的服务器，操作状态处处一致。

03 / SELF-HOSTED

数据完全自托管

所有监控与操作数据保存在你自己的数据库中，全开源代码可审计，绝不锁定、绝不上传你的数据。
