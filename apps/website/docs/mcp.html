MCP 服务 NEW

ProberX 内置 Model Context Protocol (MCP) 支持，让 Claude Desktop、Cursor、Codex CLI 等 AI 助手直接管控你的基础设施。通过 18 个标准化工具，AI 可以查看服务器状态、执行运维命令、查询告警事件，实现真正的 AIOps。

什么是 MCP？ MCP 是 Anthropic 发布的开放协议，定义了 AI 模型与外部工具/数据源之间的标准通信方式。ProberX 实现了 MCP 的 Streamable HTTP 传输层。

端点地址

https://agent.yqone.cn/api/v1/mcp

✓ 已复制

MCP 端点通过 Nginx 反向代理暴露，与 Dashboard 共用同一域名。/api/ 路径自动转发至 Dashboard 的 4000 端口。

认证方式

除 initialize 和 ping 外，所有 MCP 方法都需要 JWT Bearer Token 认证。

获取 Token

curl -X POST https://agent.yqone.cn/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"your@email.com","password":"your-password"}'

返回的 token 字段即为 JWT，有效期由 JWT_EXPIRES_IN 环境变量控制（默认 7 天）。

安全提示：请勿将 Token 直接写在配置文件里提交到 Git。建议使用环境变量或密钥管理工具。

快速接入

接入 Claude Desktop

编辑配置文件（macOS: ~/Library/Application Support/Claude/claude_desktop_config.json）：

{
  "mcpServers": {
    "proberx": {
      "url": "https://agent.yqone.cn/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_JWT_TOKEN"
      }
    }
  }
}

重启 Claude Desktop 即可在对话中调用 ProberX 工具。

接入 Cursor

Cursor Settings → MCP → Add new MCP server，填入：

{
  "name": "proberx",
  "type": "url",
  "url": "https://agent.yqone.cn/api/v1/mcp",
  "headers": {
    "Authorization": "Bearer YOUR_JWT_TOKEN"
  }
}

接入 Codex CLI

在 ~/.codex/config.toml 添加：

[mcp_servers.proberx]
url = "https://agent.yqone.cn/api/v1/mcp"
headers = { Authorization = "Bearer YOUR_JWT_TOKEN" }

使用示例

接入 MCP 后，你可以直接在 AI 对话中用自然语言运维：

# 查看所有服务器状态
"帮我看一下有哪些服务器在线？"

# 排查告警
"最近有什么告警？帮我把那个超时的告警静默掉"

# 执行命令
"在 web-server-01 上查看 nginx 错误日志最后 20 行"

# 监控分析
"检查一下 api.example.com 的 HTTPS 探测结果，最近有没有异常？"
提示：Shell AI 的 shell_ai_generate 会调用服务器上的 LLM 将自然语言转为安全命令。如果 AI 客户端自己就能生成命令，直接用 shell_ai_execute 执行即可。
